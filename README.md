# Vitra

Vitra is a coding agent for the terminal.

This repository publishes Vitra release binaries. It contains release artifacts, the license, and third-party notices only; it does not contain source code.

Vitra is a fork of [Oh My Pi](https://github.com/can1357/oh-my-pi) by Stencil Labs, which was originally a fork of [Pi](https://github.com/badlogic/pi-mono) by Mario Zechner. It is distributed under the MIT License. See [LICENSE](LICENSE) and [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt).

## Releases

Each release provides `vitra-darwin-arm64.tar.gz` for macOS on Apple Silicon and a `SHA256SUMS` file. The archive contains the `vitra` executable, the license, and the third-party notices. The executable is signed with a Developer ID and notarized by Apple.

Vitra's own settings, data, and package names keep the upstream `omp` identifiers, so existing configuration remains compatible.
